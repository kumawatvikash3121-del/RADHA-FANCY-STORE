# RADHA FANCY STORE – FINAL SHADE SCROLL V2

Final one-page Radha Fancy Store website with product categories, cart, WhatsApp ordering, clickable product cards, interactive 360°-style product preview, and a 26-shade lipstick palette.

## Lipstick Shade Feature
- 26 predefined lipstick shades from the requested shade set.
- Two-row horizontal scroll palette.
- Clicking a shade immediately changes the lipstick preview color.
- Selected shade name and HEX code are shown.
- The same shade selector is available inside the product/360° modal.
- Add to Cart and WhatsApp order include the selected shade HEX.

## Project Structure
- `index.html`
- `radha-logo.png`
- Product image folders for necklaces, earrings, cosmetics, and rings.

## Run
Open `index.html` in a browser. Keep the image folders and `radha-logo.png` in the same folder as `index.html`.
